============================================================
LOCAL DEVELOPMENT (NO DOCKER APP)
============================================================
Prerequisites: PostgreSQL running on localhost:5432
  Database: urlshortener | User: postgres | Password: postgres123

Run the app locally (IDE or CLI):
  ./mvnw spring-boot:run
  ./mvnw spring-boot:run -Dspring-boot.run.profiles=local   (explicit local profile)

Or run the JAR directly:
  ./mvnw clean package -DskipTests
  java -jar target/Url_Shortener-0.0.1-SNAPSHOT.jar

============================================================
HYBRID MODE (Docker-only PostgreSQL + Local App)
============================================================
Run just the PostgreSQL container, then run the app locally:
  docker compose up postgres -d
  ./mvnw spring-boot:run

Stop PostgreSQL when done:
  docker compose down

FULL DOCKER MODE
============================================================
docker compose up --build
docker compose up
docker compose down
docker stop $(docker ps -q): to stop all services
docker container prune : to remove all stopped containers
docker ps : to list all running containers
docker ps -a : to list all containers (running and stopped)
docker images : to list all Docker images
docker rmi <image_id> : to remove a specific Docker image
docker rmi $(docker images -q) : to remove all Docker images
docker logs <container_id> : to view the logs of a specific container
docker exec -it <container_id> bash : to access the shell of a running container
docker build -t <image_name> . : to build a Docker image from a Dockerfile
docker run -d -p <host_port>:<container_port> <image_name> : to run a Docker container in detached mode and map ports
docker compose logs : to view the logs of all services in a Docker Compose setup
docker compose logs <service_name> : to view the logs of a specific service in a Docker Compose setup
docker compose ps : to list the status of all services in a Docker Compose setup
docker compose down : to stop and remove all services in a Docker Compose setup
docker compose up -d : to start all services in a Docker Compose setup in detached mode
docker compose build : to build or rebuild services in a Docker Compose setup
docker compose restart : to restart all services in a Docker Compose setup
docker compose stop : to stop all services in a Docker Compose setup
